# THE GARDEN OF SECRETS

Одностраничный интерактивный сайт на HTML, CSS и JavaScript.

## Запуск
Откройте `index.html` в браузере. Для публикации загрузите всю папку проекта в репозиторий GitHub и включите GitHub Pages.

## Иллюстрации
Все основные иллюстрации уже подключены:
- `assets/images/lily.jpg` — белая лилия;
- `assets/images/lamb.jpg` — барашек;
- `assets/images/deer.jpg` — белый олень;
- `assets/images/tarot-star.jpg`, `tarot-moon.jpg`, `tarot-lovers.jpg` — три отдельные карты Таро;
- `assets/images/keeper.jpg` — авторский аркан XXI «The Garden Keeper»;
- `assets/images/garden.jpg` — общая сцена сада.

## Что добавить перед публикацией
- `assets/images/anya-photo.jpg` — фотография Ани для финальной сцены;
- `assets/audio/ambient.mp3` — музыка для кнопки звука.

Оба файла необязательны для локального просмотра: если их нет, сайт покажет заглушку фотографии и предложит добавить аудио.

## Личное послание
Текст в финальной сцене можно редактировать прямо на странице перед публикацией. Для постоянного изменения отредактируйте блок `#personalLetter` в `index.html`.

Подсказки, инструкции и кнопки интерфейса сделаны на русском; английский оставлен в названиях глав и декоративных заголовках.
